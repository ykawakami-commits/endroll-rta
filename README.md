# ENDROLL RTA

映画の余韻をぶっ壊せ。

スマートフォンとPCで遊べる、エンドロールのタイムアタックゲームです。

## 遊ぶ

https://ykawakami-commits.github.io/endroll-rta/

- 上スワイプ、上ドラッグ、ホイール、Space / ↑ で加速。
- 下スワイプ、逆スクロール、↓ で巻き戻し。
- 光る2つの SKIP を見つけてタップすると、大きく短縮できます。
- 音声と映画館の開始演出は画面上部から設定できます。
- 自己ベストは端末のブラウザ内に、入力方式別で保存されます。
- プレイ後に名前を登録すると、同じ入力方式のオンラインランキングで競えます。自己ベスト1件だけを登録し、順位表から自分の登録を取り消せます。
- タイム称号は A（22秒以内）・S（18秒）・SS（16秒）・SSS（12秒）。実際のオンライン順位は登録された記録から集計します。

## 公開

このリポジトリは配信用の静的ファイルです。GitHub Pagesでリポジトリのルートを公開します。ゲーム自体はHTML / CSS / JavaScriptと画像・音声で動き、ランキングの保存・操作記録の再計算は別のSites APIで実行します。通信できない場合もプレイとローカル自己ベストは利用できます。

ローカルで確認する場合は、このフォルダをHTTPサーバーで配信してください。

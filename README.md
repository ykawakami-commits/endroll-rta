# ENDROLL RTA

映画の余韻をぶっ壊せ。

スマートフォンとPCで遊べる、エンドロールのタイムアタックゲームです。

## 遊ぶ

https://ykawakami-commits.github.io/endroll-rta/

- 上スワイプ、上ドラッグ、ホイール、Space / ↑ で加速。
- 下スワイプ、逆スクロール、↓ で巻き戻し。
- 光る2つの SKIP を見つけてタップすると、大きく短縮できます。
- 音声と映画館の開始演出は画面上部から設定できます。
- 自己ベストは端末のブラウザ内に、入力方式別で保存されます。

## 公開

このリポジトリは配信用の静的ファイルです。GitHub Pagesでリポジトリのルートを公開します。HTML / CSS / JavaScript と画像・音声のみで動作し、サーバー側の処理は不要です。

ローカルで確認する場合は、このフォルダをHTTPサーバーで配信してください。
